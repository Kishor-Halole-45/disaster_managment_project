# SafeSchool Prep — Disaster Preparedness Platform

A comprehensive disaster preparedness platform for schools and communities.

## About

SafeSchool Prep provides interactive learning modules, emergency planning tools, and real-time monitoring for students, teachers, and administrators. Built to align with NDMA guidelines.

## Tech Stack

- **Vite** — fast build tool
- **React + TypeScript** — UI framework
- **Tailwind CSS** — utility-first styling
- **shadcn/ui** — component library

## Getting Started

```bash
git clone https://github.com/Kishor-Halole-45/disaster_managment_project.git
cd disaster_managment_project
npm install
npm run dev
```

The app runs at `http://localhost:8080`.

## Deployment

```bash
npm run build
```

Deploy the `dist/` folder to GitHub Pages, Netlify, or Vercel.
